ROC curve

Read the numbers honestly: next-day direction from daily technical indicators is close to an efficient-markets coin flip (ROC AUC near 0.5 above). That's expected, not a bug — the value of this project is the pipeline (live ingestion → walk-forward validated training → backtest → dashboard), not a claim of alpha.
